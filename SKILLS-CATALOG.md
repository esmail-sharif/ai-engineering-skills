# فهرس المهارات

كل المهارات مستقلة. استخدم أقل مجموعة تحقق المهمة؛ وجود مهارة لا يعني تفعيلها لكل طلب. بيانات الاسم والوصف تساعد الوكيل على اكتشاف المهارات، لكن الاختيار يعتمد على وصف واضح وإعدادات الوكيل.

## تدفقات العمل

| الطلب | المسار المقترح |
|---|---|
| فكرة غير واضحة | المنسّق → العصف الذهني → التخطيط بعد اختيار اتجاه → مهارة المجال → التحقق المناسب |
| مشروع جديد محدد | المنسّق → تخطيط المشروع → هندسة البرمجيات أو Flutter → التنفيذ → الاختبارات المناسبة |
| فهم تطبيق قائم | المنسّق → تحليل متطلبات النظام القائم → مهارة المجال |
| ميزة ويب | المنسّق → تطوير Full Stack → اختبار E2E أو API أو تدقيق واجهة حسب المخاطر |
| ميزة Flutter | المنسّق → Flutter Developer → Flutter Tests؛ أضف UI أو Architecture عند الحاجة |
| خلل | المنسّق → تحليل السبب الجذري → الاختبار المتخصص عند الحاجة |
| محاسبة أو أرقام مالية | مهارة المجال وقاعدة البيانات → Accounting Domain Validator → تحقق مناسب |
| ترقية تقنية | Code Migration Specialist → مهارة المجال → خطة رجوع وفحوصات |
| مراجعة فقط | Senior Code Reviewer؛ أضف Security Auditor إذا استدعى النطاق ذلك |

## المهارات

| الاسم | المهارة | متى تفيد |
|---|---|---|
| `engineering-workflow-orchestrator` | Engineering Workflow Orchestrator | Entry point for engineering work; delegates the task phase and relevant domain. |
| `brainstorming-facilitator` | Brainstorming Facilitator | Early exploration when the problem or solution is open-ended. |
| `project-discovery-planner` | Project Discovery Planner | A new application, major feature, or substantial rewrite that is ready to be scoped. |
| `software-architecture-expert` | Software Architecture Expert | Architecture decisions with meaningful trade-offs across components or services. |
| `senior-fullstack-developer` | Full-Stack Product Developer | A concrete web feature requires coordinated frontend and backend work. |
| `senior-code-reviewer` | Senior Code Reviewer | A user asks for review, audit of a change, or pre-merge inspection. |
| `debugging-root-cause-analyst` | Root-Cause Debugging Analyst | A specific error, regression, or unexpected result is reported. |
| `software-testing-qa-expert` | Software Testing and QA Planner | A feature needs a test strategy or a user explicitly requests QA. |
| `web-e2e-testing-specialist` | Web End-to-End Testing Specialist | A web flow must be tested across pages or user actions. |
| `responsive-ui-auditor` | Responsive UI Auditor | A page or app layout needs responsive or cross-language visual review. |
| `web-performance-optimizer` | Web Performance Optimizer | A site has a performance complaint or a requested performance review. |
| `mobile-app-testing-specialist` | Mobile App Testing Specialist | A mobile application must be validated on an emulator, simulator, or device. |
| `accessibility-ui-auditor` | Accessibility UI Auditor | The user requests an accessibility review or the change affects keyboard, screen reader, contrast, or input behavior. |
| `flutter-senior-developer` | Flutter Application Developer | A Flutter feature or bug fix is specified. |
| `flutter-architecture-specialist` | Flutter Architecture Specialist | A new Flutter app or significant structural change needs architecture decisions. |
| `flutter-ui-ux-specialist` | Flutter UI and UX Specialist | A Flutter interface is being designed or implemented from a clear user goal or reference. |
| `flutter-testing-specialist` | Flutter Testing Specialist | A Flutter change needs focused test coverage or the user requests Flutter QA. |
| `database-architect-sql-expert` | Database Architect and SQL Specialist | A project needs schema design, SQL analysis, or a data migration. |
| `application-security-auditor` | Application Security Auditor | The user requests a security review or a change affects authentication, authorization, secrets, input handling, or sensitive data. |
| `devops-deployment-specialist` | DevOps and Deployment Specialist | A deployment or infrastructure workflow is requested. |
| `reverse-engineering-requirements-analyst` | Existing-System Requirements Analyst | A current system is poorly documented or must be understood before significant changes. |
| `ai-api-integration-specialist` | AI and API Integration Specialist | A software feature connects to an external API or an AI model. |
| `technical-documentation-expert` | Technical Documentation Specialist | The user requests documentation or a code change makes existing docs inaccurate. |
| `multi-agent-orchestrator` | Multi-Agent Work Coordinator | A task has multiple separable components and parallel work would reduce elapsed time. |
| `api-testing-specialist` | API Testing Specialist | The user asks to validate an API or a change affects API behavior. |
| `code-migration-specialist` | Code and Framework Migration Specialist | A project needs a version upgrade or migration with compatibility risk. |
| `accounting-domain-validator` | Accounting and Financial Logic Validator | A change affects balances, invoices, journals, taxes, payments, or financial reports. |

## الفروق بين المهارات المتقاربة

- `brainstorming-facilitator` يستكشف البدائل؛ `project-discovery-planner` يحول اتجاهًا مختارًا إلى خطة.
- `reverse-engineering-requirements-analyst` يوثق نظامًا موجودًا؛ مخطط المشروع يحدد ما يجب بناؤه أو توسيعه.
- `ai-api-integration-specialist` يصمم أو ينفذ تكاملًا؛ `api-testing-specialist` يختبر عقد API وسلوكه.
- `software-testing-qa-expert` يحدد استراتيجية عامة؛ المهارات المتخصصة تغطي الويب أو Flutter أو API.
- المنسّق يختار المسار ولا يحل محل المهارات التخصصية.
