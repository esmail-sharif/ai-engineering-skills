# Working with this skills library

For substantial engineering tasks, start with `$engineering-workflow-orchestrator` or follow `.agents/skills/engineering-workflow-orchestrator/SKILL.md`. Consult `SKILLS-CATALOG.md` and select only the smallest set of skills that fits the task.

For an unclear product idea, use `brainstorming-facilitator`, then `project-discovery-planner` after a direction is chosen. For a defined new project, begin with the planner. For an existing system, inspect it before planning broad changes. Do not invoke all skills by default.

Skills provide workflow guidance; they do not grant tools, permissions, current documentation, or test environments. Follow the user’s instructions and the actual environment capabilities.
