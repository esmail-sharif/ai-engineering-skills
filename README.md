# مكتبة مهارات هندسة البرمجيات

مكتبة شخصية قابلة للتوسع لوكيل يعمل على الكمبيوتر. تضم مهارات للتخطيط والتنفيذ والمراجعة والاختبار لمواقع الويب وتطبيقات Flutter وقواعد البيانات والتكاملات والأنظمة المحاسبية.

## الفكرة

- المصدر الأساسي للمهارات هو `.agents/skills/`.
- يبدأ العمل الهندسي المعقد من `engineering-workflow-orchestrator`، الذي يختار أقل عدد من المهارات اللازمة.
- الفكرة الجديدة تمر بالعصف الذهني ثم التخطيط قبل التنفيذ.
- المهارات المتخصصة لا تُحمّل كاملة إلا عندما تنطبق على المهمة.
- المكتبة لا تثبّت نفسها عالميًا ولا تمنح الوكيل صلاحيات أو أدوات غير متاحة.

## البدء

1. افتح المستودع في Codex أو انسخ مجلد `.agents/skills/` إلى مجلد المهارات المعتمد في إعداد وكيلك.
2. راجع [فهرس المهارات](SKILLS-CATALOG.md) واختر المهارات التي تحتاجها فقط.
3. استدعِ مهارة مباشرةً بصيغة `$skill-name`، أو ابدأ الطلب بوصف المهمة ليختار الوكيل تلقائيًا بحسب بيانات المهارات والتعليمات المتاحة.
4. لفكرة جديدة: استخدم `$brainstorming-facilitator`، ثم `$project-discovery-planner` بعد اختيار اتجاه.

## المحتويات

- `.agents/skills/` — 27 مهارة مستقلة.
- `SKILLS-CATALOG.md` — متى تستخدم كل مهارة وكيف تتعاون مع غيرها.
- `COMPATIBILITY.md` — ملاحظات Codex وGemini CLI وIntelliJ.
- `INSTALLATION-GUIDE.md` — إعداد محلي للمستخدم أو للمشروع.
- `SECURITY.md` — حدود الأمان والخصوصية.
- `CHANGELOG.md` — سجل الإصدارات.

تعليمات `SKILL.md` مكتوبة غالبًا بالإنجليزية لإعادة استخدامها بين الوكلاء؛ دليل المستودع والفهرس بالعربية.
